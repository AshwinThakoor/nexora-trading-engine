# Project Structure

- `analytics/` — offline analytics and reporting scripts.
- `tools/` — utilities for dataset merging and training-event generation.
- `signal_server.py` — main Python signal server code.
- `README.md` — overview and safety guidance.
- `.gitignore` — excluded runtime artifacts.
- `.github/` — GitHub metadata and workflows.
- `data/`, `models/`, and `logs/` are excluded from source control.
