# FAQ

## What is this repository?

This is an experimental trading engine research/demo system for MT5 signal generation.

## Is this approved for live trading?

No. It is not approved for live trading and provides no profitability guarantee.

## Are model weights included?

No. Model weights and private datasets are excluded from source control.

## What CI checks are safe?

CI should use compile-only checks, import validation, and repository hygiene. Do not start servers or connect to brokers.
